====================================================
Reading Material
====================================================

Supplemental reading material covering SQL topics required for group
projects that have not yet been presented in a formal lecture. These pages
are self-contained references: each one introduces a topic from scratch
with syntax, examples, result tables, and GP2-style worked queries.

   * - :doc:`select_aggregates_subqueries`

       ``OFFSET``), aggregate functions (``COUNT``, ``SUM``, ``AVG``,
       ``MIN``, ``MAX``), ``GROUP BY``, ``HAVING``, non-correlated and
       correlated subqueries (``IN``, ``ANY``, ``ALL``, ``EXISTS``),
       derived tables, scalar subqueries
